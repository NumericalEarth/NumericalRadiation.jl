# API Reference

The public API is split by workflow:

- [Staged runtime](api/staged_runtime.md) covers column states, optical-property work arrays,
  cloud/aerosol optics, flux solvers, and heating-rate conversion.
- [ecCKD and data](api/ecckd.md) covers official ecCKD model selection, artifact
  resolution, CKD-definition schemas, and scattering-table readers.
- [Column schemes](api/column_schemes.md) covers the older analytic-band column wrapper,
  longwave and shortwave schemes, solar geometry, and thermodynamics helpers.
- [Metrics](api/metrics.md) covers validation thresholds and error summaries.
