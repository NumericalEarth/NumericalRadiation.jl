NumericalRadiation.ColumnAtmosphere — Type
struct ColumnAtmosphere{FT, A, G, S, Geo} <: AbstractAtmosphericState

Generic column atmosphere container for the staged radiation interface.

The existing analytic-band solvers use AtmosphereProfile, ColumnGrid, and SurfaceState directly. ColumnAtmosphere is a host-model-facing container for newer gas-optics and solver paths where layer/interface pressure and temperature arrays need to be carried together.

Fields are

  • pressure_layers::Any: Layer pressures, indexed top-down.

  • pressure_interfaces::Any: Interface pressures, indexed top-down.

  • temperature_layers::Any: Layer temperatures, indexed top-down.

  • temperature_interfaces::Any: Interface temperatures, indexed top-down.

  • gases::Any: Symbol-keyed gas concentrations or host-model property view.

  • surface::Any: Lower-boundary state.

  • geometry::Any: Geometry, solar angles, or host-model geometry view.

NumericalRadiation.LongwaveOptics — Type
struct LongwaveOptics{FT, A, ST, SB, SA, SG, W}

Precomputed longwave optical properties for clear-sky solver tests and future ecCKD gas-optics outputs.

optical_depth and source may be vectors of length nlayers or matrices with shape (ng, nlayers). source is the layer source function in flux units for each spectral point. Optional source_top and source_bottom arrays with the same shape enable ecRad-style no-scattering longwave emission from half-level Planck functions. Optional single_scattering_albedo and scattering_asymmetry arrays activate the ecRad-style longwave scattering adding path. weights has length ng and is applied while accumulating broadband fluxes.

Fields are

  • optical_depth::Any: Layer optical depth.

  • source::Any: Layer source function in flux units.

  • source_top::Any: Top-interface source function for each layer, or nothing.

  • source_bottom::Any: Bottom-interface source function for each layer, or nothing.

  • single_scattering_albedo::Any: Layer single-scattering albedo, or nothing for no scattering.

  • scattering_asymmetry::Any: Layer scattering asymmetry factor, or nothing for no scattering.

  • weights::Any: Spectral weights.

NumericalRadiation.LongwaveBoundaryConditions — Type
struct LongwaveBoundaryConditions{FT, S, A}

Longwave boundary fluxes for CloudlessLongwave.

For spectral (multi-g) optics such as the tabulated ecCKD models, surface_longwave_up must be a length-ng vector in the same per-unit-weight convention as the optics' Planck sources — build it with surface_longwave_emission. A scalar is interpreted as spectrally-gray emission (every g point emits the same flux), a gray approximation that does not reproduce a tabulated model's Planck spectrum and may bias outgoing longwave fluxes.

Fields are

  • surface_longwave_up::Any: Upwelling longwave flux entering the bottom interface.

  • toa_longwave_down::Any: Downwelling longwave flux entering the top interface.

  • surface_albedo::Any: Diffuse longwave surface albedo.

NumericalRadiation.CloudlessShortwave — Type
struct CloudlessShortwave <: AbstractRadiativeTransferSolver

Cloudless shortwave solver for precomputed absorptive optical depths.

This is a deterministic clear-sky component solver. It transmits downwelling TOA shortwave flux through the column, reflects a configurable fraction at the surface, and transmits that reflected flux upward through the same optical depths.

NumericalRadiation.LayerCloudOpticsModel — Type
struct LayerCloudOpticsModel{FT, CWP} <: AbstractCloudOpticsModel

Simple layer-cloud optical model.

cloud_water_path may be a scalar, a vector with one entry per layer, or an object supporting getproperty(..., :cloud_water_path). Optical depths are

τ_lw = longwave_mass_absorption * cloud_water_path
τ_sw_abs = (1 - ω0) * shortwave_mass_extinction * cloud_water_path
τ_sw_scat = ω0 * shortwave_mass_extinction * cloud_water_path

Fields are

  • cloud_water_path::Any: Layer cloud water path, or fallback value when the atmosphere does not provide one.

  • longwave_mass_absorption::Any: Longwave mass absorption coefficient.

  • shortwave_mass_extinction::Any: Shortwave mass extinction coefficient.

  • shortwave_single_scattering_albedo::Any: Shortwave single-scattering albedo.

  • shortwave_scattering_asymmetry::Any: Shortwave scattering asymmetry factor.

NumericalRadiation.LayerLiquidIceCloudOpticsModel — Type
struct LayerLiquidIceCloudOpticsModel{FT, LWP, IWP, CF} <: AbstractCloudOpticsModel

Layer liquid/ice cloud optical model for all-sky host integrations.

This keeps liquid water path, ice water path, and cloud fraction as separate inputs instead of collapsing them before the cloud-optics API. The current model is still absorptive/extinctive-only, but it gives later IFS-compatible cloud optics a stable place to add phase-dependent scattering, asymmetry, effective-radius, and overlap conventions.

Optical depths are

τ_lw = f_cloud * (κ_lw_liq * LWP + κ_lw_ice * IWP)
τ_sw_abs = f_cloud * ((1 - ω0_liq) * κ_sw_liq * LWP
                    + (1 - ω0_ice) * κ_sw_ice * IWP)
τ_sw_scat = f_cloud * (ω0_liq * κ_sw_liq * LWP
                     + ω0_ice * κ_sw_ice * IWP)

Fields are

  • liquid_water_path::Any: Layer liquid water path, or fallback value when the atmosphere does not provide one.

  • ice_water_path::Any: Layer ice water path, or fallback value when the atmosphere does not provide one.

  • cloud_fraction::Any: Layer cloud fraction, or fallback value when the atmosphere does not provide one.

  • liquid_longwave_mass_absorption::Any: Liquid longwave mass absorption coefficient.

  • ice_longwave_mass_absorption::Any: Ice longwave mass absorption coefficient.

  • liquid_shortwave_mass_extinction::Any: Liquid shortwave mass extinction coefficient.

  • ice_shortwave_mass_extinction::Any: Ice shortwave mass extinction coefficient.

  • liquid_shortwave_single_scattering_albedo::Any: Liquid shortwave single-scattering albedo.

  • ice_shortwave_single_scattering_albedo::Any: Ice shortwave single-scattering albedo.

  • liquid_shortwave_scattering_asymmetry::Any: Liquid shortwave scattering asymmetry factor.

  • ice_shortwave_scattering_asymmetry::Any: Ice shortwave scattering asymmetry factor.

  • cloud_fraction_exponent::Any: Exponent applied to cloud fraction before scaling optical depth.

NumericalRadiation.CloudyRegionCloudOptics — Type
struct CloudyRegionCloudOptics{FT, A}

Cloudy-region cloud optical properties for all-sky solvers.

Unlike CloudOptics, these optical depths are not scaled by cloud fraction. They describe the cloudy region of each layer, while cloud_fraction and overlap_parameter are carried separately for Tripleclouds/McICA-style solvers. This avoids the grid-mean shortcut that is useful for simple smoke tests but inconsistent with ecRad's all-sky cloud-region optical-property convention.

Fields are

  • cloud_fraction::Any: Layer cloud fraction.

  • overlap_parameter::Any: Interface cloud-overlap parameter between adjacent layers.

  • longwave_optical_depth::Any: Cloudy-region longwave cloud optical depth.

  • shortwave_optical_depth::Any: Cloudy-region shortwave absorptive cloud optical depth.

  • shortwave_scattering_optical_depth::Any: Cloudy-region shortwave scattering cloud optical depth.

  • shortwave_scattering_asymmetry::Any: Cloudy-region shortwave cloud scattering asymmetry factor.

NumericalRadiation.CloudOverlapLongwave — Type
struct CloudOverlapLongwave{FT} <: AbstractRadiativeTransferSolver

First deterministic all-sky longwave overlap solver.

overlap=:adding mixes clear/cloudy layer reflectance, transmittance, and source terms before a scalar longwave adding pass. overlap=:tripleclouds_alpha splits cloudy layers into thin and thick regions using the same gamma inhomogeneity scaling as the staged shortwave Tripleclouds access point. This is still a diagnostic solver, not a bit-for-bit ecRad McICA implementation.

source
NumericalRadiation.CloudOverlapShortwave — Type
struct CloudOverlapShortwave{FT, S} <: AbstractRadiativeTransferSolver

First deterministic all-sky shortwave overlap solver.

This solver computes clear-region and cloudy-region fluxes independently using CloudlessShortwave, then blends each interface by an explicit interface cloud fraction. It is a staged all-sky access point, not a full ecRad McICA/Tripleclouds implementation.

overlap=:maximum uses the maximum adjacent layer cloud fraction at interior interfaces, which preserves vertically contiguous cloud cover more strongly than averaging. overlap=:average uses the arithmetic mean. overlap=:adding mixes clear/cloudy layer reflectance and transmittance before the adding pass. overlap=:matrix_maximum carries separate clear/cloudy region fluxes through a two-region maximum-overlap matrix during the adding pass. overlap=:matrix_alpha uses the supplied ecRad/Hogan-Illingworth alpha overlap parameter between adjacent layers. overlap=:tripleclouds_alpha additionally splits the cloudy region into thin and thick regions using ecRad's gamma optical-depth scaling. These latter modes are diagnostics between final-flux blending and a full Tripleclouds/McICA solver.

Fields are

  • clear_solver::Any: Underlying two-stream shortwave solver.

  • overlap::Symbol: Cloud-fraction overlap rule: :maximum or :average.

  • cloud_fraction_exponent::Any: Exponent applied to layer cloud fraction before interface blending.

  • inhomogeneity_overlap_exponent::Any: Exponent applied to alpha overlap inside the Tripleclouds inhomogeneity split.

NumericalRadiation.CloudScatteringTable — Type
struct CloudScatteringTable{FT, V, M}

Dependency-light cloud scattering table.

The table stores raw ecRad-style scattering properties as a function of wavenumber and effective radius. Spectral mapping to radiation bands or g-points is a separate operation because it depends on the gas-optics spectral definition and averaging convention.

Fields are

  • medium::String: Hydrometeor medium, for example liquid-water or ice.

  • particle_type::String: Particle type from file metadata.

  • wavenumber::Any: Wavenumber grid in cm^-1.

  • effective_radius::Any: Effective-radius grid in m.

  • mass_extinction_coefficient::Any: Mass-extinction coefficient with shape (wavenumber, effective_radius).

  • single_scattering_albedo::Any: Single-scattering albedo with shape (wavenumber, effective_radius).

  • asymmetry_factor::Any: Scattering asymmetry factor with shape (wavenumber, effective_radius).

add_mapped_cloud_scattering!(shortwave, liquid_properties, ice_properties,
                             liquid_water_path, ice_water_path, cloud_fraction; kwargs...)

NumericalRadiation.heating_rates! — Function
heating_rates!(heating, fluxes, atmosphere[, workspace])

Convert flux divergence to heating rates. Concrete atmosphere/flux pairings should overload this method when they do not use the existing column tendency helpers.

source
heating_rates!(heating, fluxes::RadiativeFluxes, atmosphere::ColumnAtmosphere;
               gravity, heat_capacity)

Convert interface fluxes to layer heating rates in K s^-1.

Conventions:

  • vertical indexing is top-down;
  • pressure interfaces increase downward;
  • net flux is positive downward;
  • positive heating means atmospheric warming.

For layer k, the heating rate is

gravity / heat_capacity * (F_net[k] - F_net[k + 1]) / Δp[k]

where F_net = longwave_down - longwave_up + shortwave_down - shortwave_up.

source
heating_rates!(heating, rtm::RadiativeTransferColumn)

Copy the current column temperature tendency into heating. This method gives the staged interface an allocation-free bridge to the existing analytic-band workspace.

NumericalRadiation.cloud_scattering_gpoint_properties — Function
cloud_scattering_gpoint_properties(table, mapping, effective_radius)

Map raw cloud-scattering table properties onto an ecCKD g-point grid using the resolved spectral intervals and gpoint_fraction weights from an EcCKDSpectralMapping. Returns vectors of mass extinction, single-scattering albedo, and asymmetry factor with one entry per g-point.

The current mapper samples the nearest cloud-scattering table wavenumber at each ecCKD interval midpoint and uses interval width times g-point fraction as the quadrature weight. Single-scattering albedo is extinction-weighted, and asymmetry is scattering-extinction-weighted.
